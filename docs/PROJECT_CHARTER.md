## Objective
Deliver a professional, modular, secure, locally runnable prototype with role-specific back offices, traceable workflows and verifiable tests, ready for institutional review.

## In scope (current stage)
Requirements reconciliation, architecture, design system, local synthetic-data prototype of MVP modules, tests and documentation.

## Out of scope (current stage)
Production hosting, real data, police network connection, production identity, procurement, security accreditation, national rollout, any paid service.

## Stop conditions
Stop and record a decision before anything that needs real Police data, Police network access, production authentication, external hosting, paid services or formal institutional approval.

## Governance
Decisions: DECISION_REGISTER.md. Assumptions: ASSUMPTIONS_REGISTER.md. Exit gates: Phase 1 tracker v1.2 (12 gates — none signed in this repository).

## Success criteria for this stage
All MVP modules functional on synthetic data; every Part Q scenario covered by an executed automated test; zero spend; documentation complete and consistent with the code.
