# ZPS-OMS Phase 1 Supporting Documentation Suite v1.0

**Date:** 25 November 2026  
**Status:** Draft for institutional validation — not approved for production.

## Fixed scope
Service Headquarters under the Deputy Inspector General – Operations; the ten Provincial Police Divisions; and authorised Divisional Units/formations within the approved DIG Operations structure. Districts, police stations, police posts and training management are excluded.

## Zero-funding rule
No additional cash funding is requested for the present documentation, discovery planning and local synthetic-data prototype stage. Use only already available, permitted tools and in-kind effort. No paid subscriptions, APIs, hosting, hardware, travel, consultancy, procurement or licences are authorised. Pause if any cost, real Police data, production access or unapproved service becomes necessary.

## Important status
These are prepared working documents, not signed Police policy or institutional approval. Internal interviews, current approved organisation chart, business owners, data classification, system-of-record mapping, security/toolchain approval and Phase 1 exit sign-off remain outstanding.

## Claude Code usage
Copy these documents into the approved ZPS-OMS repository under `docs/phase1/supporting/`. Start with `prompts/00-repository-audit-no-code.md` from the existing Claude Code Phase 1 pack. Run discovery and consistency checks in Plan Mode. Do not begin feature coding until Phase 1 exit gates are approved.

## Data and security
Synthetic data only. No real police names, IDs, duty rosters, locations, vehicles, equipment records, correspondence, incident details, secrets or credentials. Do not submit restricted Police information to an external AI coding tool or unapproved repository.
