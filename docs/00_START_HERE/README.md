## Current project boundary
Service Headquarters under the Deputy Inspector General – Operations; ten Provincial Police Divisions; and authorised Divisional Units/formations within the current approved DIG Operations structure. Districts, police stations, police posts and training management are excluded. The system is for administrative operations support only. Tactical plans, intelligence, surveillance, live officer tracking, patrol routes, sensitive case/evidence content and dispatch are excluded.

## Zero-funding rule
No additional cash funding is requested or authorised for the current documentation, requirements, design and local synthetic-data prototype stage. Use only existing permitted resources and in-kind effort. No paid Claude Code credits/upgrades, subscriptions, APIs, hosting, licences, hardware, travel, consultancy or procurement. Stop if a cost is required. Production hosting, live-data processing, security accreditation and national rollout are not included in this current-stage commitment.

## Data rule
Public-source and fabricated synthetic data only. No real Police data, officer identifiers, rosters, vehicle details, equipment records, internal correspondence, sensitive unit details, credentials or secrets in Claude Code or other unapproved tools.
