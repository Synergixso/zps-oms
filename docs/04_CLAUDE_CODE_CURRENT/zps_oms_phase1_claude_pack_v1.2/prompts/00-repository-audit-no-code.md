# Prompt 00 — Repository and Documentation Audit (No Code Changes)

## C — Concise task
Perform a read-only audit of the existing ZPS-OMS repository and the Phase 1 documents. Do not implement features or modify application code.

## L — Logical sequence
1. Read `CLAUDE.md` and `.claude/rules/`.
2. Inspect repository tree, README, package manifests, lockfiles, existing docs, scripts, tests and Git state.
3. Determine the BMad Method version/workflow actually present. Do not install or upgrade anything.
4. Review the Phase 1 DOCX and tracker; identify conflicts, missing links, stale assumptions and document-version inconsistencies.
5. Identify any tools or dependencies that would require payment, a new account, external data transfer or privileged access.
6. Prepare a read-only audit report and proposed reconciliation plan.

## E — Explicit constraints
- Do not write or modify any source files.
- Do not connect to Police systems or networks.
- Use public and synthetic material only.
- Do not include actual police data in prompts or output.
- No paid upgrades, subscriptions, API calls, hosting or procurement. Stop if any task requires payment.
- Keep the exact Operations-only scope: DIG Ops HQ, ten Provincial Divisions and authorised DIG Ops formations; no districts, stations, posts or training system.
- Do not infer organisational reporting lines or delegated authority.

## A — Adaptive handling
If a document, approval, organisation chart or system inventory is missing, record it as an open question/decision with the proposed authority and evidence required. Do not invent it.

## R — Reflective verification
