# Prompt 05 — Verification, Evidence and Phase Gate

Conduct a verification review of the Phase 1 documentation and, only if authorised, the local synthetic prototype.

1. Map every accepted candidate requirement to evidence, design, test and approval.
2. Execute only local synthetic-data tests.
3. Verify cross-division and cross-formation denial at API/service/data layers; test export scope and technical/business privilege separation.
4. Verify no excluded feature or real police data exists in code, seed data, screenshots, logs, prompts or exported artefacts.
5. Verify no new paid dependency, account, API, hosting or service was activated.
6. Identify all incomplete security, privacy, legal, hosting and operational-readiness tasks.
7. Review open decisions and exit gates. No pending gate may be represented as approved.
8. Produce a Phase 1 exit recommendation: Ready for institutional sign-off / Not ready, with evidence and blockers.

Do not claim production security, legal compliance or institutional acceptance based on automated local tests. No production deployment. No funding request.
