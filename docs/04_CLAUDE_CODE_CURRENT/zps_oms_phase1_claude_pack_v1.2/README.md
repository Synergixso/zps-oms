# ZPS-OMS Claude Code Phase 1 Documentation Pack v1.2

This is the current Phase 1 working pack. It consolidates the v1.1 Claude Code rules/prompts with the v1.2 tracker and the nine supporting discovery documents.

## Start here
1. Read `CLAUDE.md` and all `.claude/rules/`.
2. Read `docs/phase1/01-project-charter-and-zero-funding.md` and `docs/phase1/02-scope-and-organisational-baseline.md`.
3. Read `artifacts/phase1/ZPS-OMS_Phase1_Complete_Documentation_Pack_v1.1.docx` and the current v1.2 tracker.
4. Read all files in `docs/phase1/supporting/`.
5. Start with `prompts/00-repository-audit-no-code.md`. Keep Claude Code in Plan Mode for discovery and consistency work.

## Scope
Service Headquarters under DIG Operations, the ten Provincial Divisions and authorised Divisional Units/formations within the approved DIG Operations structure. Districts, stations, posts and training management are excluded.

## Zero funding
No additional cash funding is requested or authorised for the current documentation, requirements, design and local synthetic-data prototype stage. Do not buy credits, subscriptions, licences, paid APIs, cloud hosting, devices or services. Pause if any activity would incur a cost.

## Data restrictions
Use public information and fabricated synthetic data only. Do not submit real police information, credentials, restricted internal documents, operational plans or sensitive system details to Claude Code or any external service unless formally approved by the Service. Production deployment and live-data processing are outside this stage.

## Status
Prepared for institutional validation. Nothing in this pack constitutes High Command approval, technical accreditation, legal advice or authority to process Police data.
