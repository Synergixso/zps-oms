# DIG Operations — Portfolio Coverage Matrix

Final master directive, Part D (28 Nov 2026). v0.15.0. Status: **V** verified · **P** partial · **O** outside approved scope · **D** external dependency.

**Office and access.** DIG Operations (`pos_dig_ops`, role 03, NATIONAL) reports directly to the IG and coordinates Police operations nationwide (official website R4: Provinces; Crime Prevention and Support Services; Paramilitary Battalion; TAZARA Division; Kamfinsa SPOM / Mobile Unit; Airport Division; Protective Unit; Police Air Wing; National Command Centre). It has no authority over DIG Administration or DIG Special Duties / State House; cooperation uses coordination requests (DEC-088).
