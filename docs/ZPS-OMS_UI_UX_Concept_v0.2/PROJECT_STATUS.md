# ZPS-OMS UI/UX Concept v0.2 — Project Status

**Status:** Professional visual redesign and local frontend prototype prepared.

**Scope:** DIG Operations Headquarters, Provincial Divisions and authorised Divisional Formations only.

**Brand asset:** Exact user-supplied Zambia Police Service crest embedded locally and used in the shared shell across all screens.

**Institutional colours:** Green → white → blue top band, following the user's required order. Hex values are provisional screen tokens, not official specifications.

**Cost:** ZMW 0 additional cash expenditure for this local prototype. No paid services or remote dependencies are used.

**Functional status:** Nine screens and demonstration interactions operate locally. No real backend, persistent storage, authentication or police data connections exist.

**Verification:** Headless Chromium smoke checks passed for nine-screen navigation, logo rendering, provincial and fleet search, modal Escape close and focus return, mobile drawer behaviour, and 390px viewport horizontal overflow. A full accessibility and user acceptance audit remains outstanding.

**Approval:** This is a design concept and is not an official or authorised Zambia Police Service system. Production use requires institutional approval and security/legal review.
