# Change log — ZPS-OMS UI/UX Concept

## v0.2 — Professional visual redesign

- Replaced the initial v0.1 visual design with a restrained government-enterprise application shell.
- Incorporated the exact Zambia Police Service crest image supplied by the user; embedded locally and used in the shared shell on all nine screens.
- Applied the requested green → white → blue institutional sequence in the top band.
- Refined page hierarchy, typography, navigation, table layout, cards, forms, empty states, badges, modal and responsive navigation.
- Expanded the page set into nine explicit screens: overview, provincial divisions, divisional formations, fleet & transport, maintenance, assets & equipment, administrative requests, reports & insights, and users & permissions.
- Added working local-only search, basic table filters, dialogs and demonstration form acknowledgement.
- Added dialog focus return and keyboard focus handling.
- Improved supporting text contrast and maintained text labels alongside status colours.
- Removed remote crest dependencies; all required assets are local.
- Added Claude Code handoff, screen specifications, brand asset rules and updated design system.
- Added desktop/mobile screenshots and nine individual screen captures.
